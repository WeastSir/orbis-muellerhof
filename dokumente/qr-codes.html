QR-Codes für deine Projektarbeit

Hier findest du alle QR-Codes, die zu den versteckten Seiten führen. Drucke sie aus und klebe sie in deine schriftliche Arbeit.

Sobald du tippst, werden alle QR-Codes automatisch aktualisiert. Beispiel: https://maxmuster.github.io/orbis-muellerhof

📋 So gehst du vor

  1. Lade deine Dateien (PDF, Video) in den entsprechenden Ordner hoch
  2. Lade alles auf GitHub hoch und aktiviere GitHub Pages
  3. Trage deine GitHub Pages URL oben ein
  4. Lade die QR-Codes als PNG herunter oder drucke diese Seite direkt
  5. Klebe sie an die passenden Stellen in deiner schriftlichen Arbeit
